# 8. 근거와 적용 범위

가이드의 요구사항과 구현 방법은 구분해서 읽어야 한다.

입력 설명과 검증의 일치는 호출자가 의지하는 계약이다. 공통 선언에서 둘을 생성하는 것은 이를 유지하는 방법이다. 임시 홈은 자체 상태를 가진 도구의 테스트 패턴이다. 이들을 같은 수준의 필수 기능으로 다루면 필요하지 않은 장치까지 도구에 추가하게 된다. 권고가 적용되는 조건과 다른 선택이 적절한 경우를 설명한다.

입력 검증·관측 가능한 상태·테스트 가능한 의존성은 AI 이전에도 유용했다. 에이전트에게 유용하다는 사실만으로 역사적 새로움이나 성능 향상이 입증되는 것은 아니다. 성능과 정확성에 관한 주장은 측정한 조건과 근거를 함께 제시한다. 생성된 스키마만으로 모든 핸들러가 이를 따른다고 증명할 수는 없다.

이 가이드는 CLI를 선택했을 때의 설계를 다룬다. CLI·MCP 등의 선택은 환경에 따라 달라지며, 특정 하네스·언어·패키지 매니저를 전제하지 않는다.

## 예시와 구현 지원 범위

문서의 명령·응답·파일 구조는 설계 선택을 설명하는 예시다. 정확한 명령 이름과 필드명, 지식 조립 API를 공통 규격으로 정하지 않는다.

TypeScript 참조 구현의 동작은 특정 리비전을 기준으로 비교한다. 가이드가 권하는 기능과 패키지가 현재 제공하는 기능을 구분하고, 코드가 바뀌면 지원 범위도 갱신한다.

## 참조 구현의 지원 범위

[TypeScript 구현](https://github.com/zeakd/cli-for-ai-ts)은 구체적인 사례이며 이 문서의 모든 권고를 이미 구현했다는 뜻은 아니다. 아래 비교는 [리비전 5a88fff1d5b31416e2f6675e8bb7ab23023706a9](https://github.com/zeakd/cli-for-ai-ts/tree/5a88fff1d5b31416e2f6675e8bb7ab23023706a9)를 기준으로 고정했다. 이후 리비전은 다를 수 있다.

| 영역 | 해당 리비전의 동작 | 이 가이드가 설명하는 계약 |
| --- | --- | --- |
| 명령 탐색과 도움말 | 루트·그룹의 인자 없는 호출은 `--help`와 같은 도움말 제공 | 필수 호출 정보와 결과 정보를 도움말에서 제공; 구조화된 내보내기는 선택적 |
| 출력 | 일반 결과는 기본 JSON; 명시적인 `--human`, 렌더러가 없으면 읽기 좋은 JSON | 표현 방식과 무관하게 같은 실행 |
| 오류 채널 | 일반 성공·실패는 stdout; 페이로드 명령으로 식별되면 오류는 stderr | 페이로드 stdout을 오류·진단과 분리 |
| 출력 선언 | 선택적 파서가 성공 데이터를 검증; 따로 제공한 출력 스키마는 설명용; 도움말에는 출력 요약과 작성자가 제공한 필드 설명 | 해석과 연결에 필요한 결과 구조 제공; 이 구현은 파서에서 전체 출력 구조를 생성하지 않음 |
| 페이로드 스트림 | JSONL 객체 레코드와 LF/NUL 텍스트 레코드; 쓰기 백프레셔 적용; 부분 실패는 stderr에 진행 상황 보고; 수신 측 조기 종료는 전체 내보내기 실패 | 프레이밍·실패 채널·완료·수신 측 조기 종료 정책 선언; 실패 시 마지막 레코드 일부만 남을 수 있음 |
| 입력 | 모르는 입력·누락·초과 입력 거절; 선언된 값·입력 간 제약 적용; stdin 형태 검사는 컨텍스트 생성 전 수행 | 계약 밖 입력 거절; 도움말은 생략한 실행 입력을 요구하지 않고 제공된 입력 검증 |
| 명령군 라우팅 | 그룹은 도움말 제공; 모르는 명령은 실패 | 명령군에 암묵적 실행 없음 |
| 후속 행동 | 구조화된 결과 액션과 힌트 미구현 | 성공·실패에 관련 행동과 힌트 제공 가능 |
| 사용 지식 | 명령 도움말과 검증된 예제; 저술 스킬 표면 없음 | 필요할 때 도움말에서 관련 작업 흐름에 도달 가능 |
| 실행 상태 | 완료·접수·실패 결과; 보고 실패 시 알려진 반환 상태 보존; 취소가 롤백을 보장하지 않음 | 작업 특성에 따라 부분 실행과 결과 미확정도 구분 |
| 제작·검증 | 공통 선언, 컨텍스트 주입·정리, 실제 프로세스 테스트 | CLI 경계 검증을 포함한 유용한 구현 방법 |

페이로드 진행 상황 보고를 넘어서는 후속 행동·부분 작업 결과·스킬 계약은 이 리비전에 구현되지 않았으며, 이 장들만 보고 지원한다고 가정해서는 안 된다. 가이드의 `tool` 명령은 설계 예시이며 해당 패키지의 실행 예제가 아니다. 필드명과 정확한 스킬 명령 이름은 구현이 정하며, 동작의 구분이 가이드의 권고다.

해당 구현을 평가할 때는 [고정된 소스](https://github.com/zeakd/cli-for-ai-ts/tree/5a88fff1d5b31416e2f6675e8bb7ab23023706a9/src)를 사용한다. 코드가 바뀌면 지원 범위도 버전과 함께 관리한다. 동작을 지원한다고 설명하기 전에 생성된 사실과 저술된 예제를 모두 검증한다.
